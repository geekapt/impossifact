Privacy policy

Impossifact Autopilot · last updated 22 November 2026

What the app is

Impossifact Autopilot is a private desktop tool used only by the owner of the Impossifact YouTube channel. It is not a public service, and no one else signs in to it.

What Google data it accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API and YouTube Analytics API to:

  • upload the channel's own videos, thumbnails and playlist entries;
  • read the channel's own video statistics, analytics reports and public comments, to improve future videos.

How the data is stored and shared

OAuth tokens and analytics data are stored only on the owner's own computer. They are never sold, shared with third parties or used for advertising. The app does not collect data about viewers or any other users.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
